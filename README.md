# IpVaultX 🔐

IpVaultX is a state-of-the-art, decentralized intellectual property (IP) protection system. Built by a team of Data Science students from ABES Institute of Technology, it leverages blockchain technology to provide immutable, encrypted, and globally verifiable proof of ownership for digital assets.

## 🚀 Key Features

*   **SHA-256 Fingerprinting:** Every file is hashed locally to generate a unique digital fingerprint.
*   **IPFS Integration:** Metadata and hashes are stored across a decentralized network to ensure zero downtime and censorship resistance.
*   **On-Chain Certificates:** Validated IP registrations are minted as unique certificates on the Ethereum blockchain.
*   **Privacy-First:** Files are hashed in the browser; your original content never leaves your device.
*   **Premium Web3 UI:** A high-end, responsive interface designed for a seamless user experience.

## 🛠️ Tech Stack

*   **Frontend:** React, TypeScript, Vite, Tailwind CSS, Framer Motion
*   **Blockchain:** Ethereum, Solidity, Ethers.js
*   **Storage:** IPFS (via Pinata/Infura)
*   **Icons:** Lucide React

## 📂 Project Structure

*   `/frontend`: The complete React application source code.
*   `Research paper - final.pdf`: The detailed research foundation for the IpVaultX protocol.

## 🚦 Getting Started (Frontend)

1.  Navigate to the `frontend` directory:
    ```bash
    cd frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
